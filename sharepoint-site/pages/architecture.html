Trusted APAC outputs start with Global EDI's Gold View

For end users, the important point is simple: approved dashboards, reports and extensions are built from a curated Global EDI source and carry documented APAC business definitions.

A clear ownership boundary

Global EDI

Curates the upstream data

Global EDI owns source extraction, ETL and the Gold View that forms the approved entry point.

APAC Data & Analytics

Prepares data for local use

We apply documented local business logic, validation and security needed to create stable consumer outputs.

Business owners

Approve meaning and use

You validate measures, scope, exceptions and acceptance criteria before a delivery is released.

From curated data to a business output

1Global EDI Gold View

The approved upstream data product and schema contract.

2APAC consumption preparation

Only the local integration or harmonisation that the agreed business requirement needs.

3Certified consumption view

Stable business fields, measures, refresh metadata and accountable ownership.

4Semantic model

Relationships, approved calculations and access controls for the chosen BI tool.

5Business output

A dashboard, report or approved extension that users can trust and support.

Why this matters: this is a focused APAC consumption pattern. It does not recreate Global EDI's upstream ETL responsibility.

What makes an output trustworthy

Definition

Meaning is clear

Each key field and measure has a plain-English definition, grain and owner.

Lineage

Origin is visible

We can trace a result back to a named Gold View source and approved local logic.

Freshness

Timing is known

Refresh timestamps, effective dates and reporting periods show when data is valid.

Control

Access is appropriate

Quality checks, security roles and exception handling are tested before release.

Technical reference for delivery teams

Object typeUseMinimum controls
Reference (REF)Business context and hierarchyNatural key, attributes, effective dates and owner.
Metric (MET)Business event or snapshotDeclared grain, measures, dimension keys and event date.
Link (LNK)Legitimate many-to-many relationshipBoth keys, relationship type, allocation and validity dates.
Rollup (RUP)Approved reusable aggregationAggregation grain, period/as-of rule and refresh timestamp.
