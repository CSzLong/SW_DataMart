How to use the integrated template

1

Tell the business story

Start with the decision, user outcome, business rules and scope—not the data objects.

2

Show the evidence

Insert a lineage diagram, dashboard wireframe, report sample or screenshot. Paste only reviewed code or link to source control.

3

Record approval and support

Link the completed document to the delivery register with owners, validation evidence and release status.

Document simplification: The integrated design template is the primary staff document. Use tables only for true inventories and data dictionaries; explain business logic and design decisions in clear narrative sections.
