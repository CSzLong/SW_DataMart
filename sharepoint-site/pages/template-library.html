How to use the library

1

Copy, then identify

Save a working copy, assign the DRIVE ID and name the business and technical owners.

2

Complete what applies

Use DA, VI, RP and EX sections only for components in scope, while keeping validation and release controls.

3

Link to the register

Record the document link, owners, status, Top Coat contract and validation state in the delivery register.

Document simplification: The integrated design template is now the primary staff document. The former component-specific standards are retained in the repository only as reference material; do not start a new request from them.
