# SW Data Mart — Architecture Deliverables

This folder contains the English architecture pack generated from the project README.

- `SW_DataMart_Architecture_Overview.pptx` — executive and implementation presentation.
- `documentation/` — the DRIVE governance standard plus four controlled Word standards and a catalogue README.
- `SW_DataMart_Architecture_Hub.html` — local, browsable architecture hub; double-click to open it in a browser.
- `../architecture-hub/` — editable source copy of the local hub.

The documentation normalizes working object IDs to `DA`, `VI`, `RP`, and `EX`. The README's original DRIVE mnemonic remains valid; its Validation element is implemented as a mandatory control plane across every deliverable class.
