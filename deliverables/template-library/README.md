# Data Analytics Template Library

Use this folder as the single staff-download location. Every enhancement is identified by a `DRIVE-###` ID and uses only the applicable two Word document types below.

| Template | Use it for |
|---|---|
| `DA-100_Data_Architecture_Design_Template.docx` | Global EDI Gold View source, Refined Coat / Sealer Coat manipulation process, programs/tools, RC/SC objects, mapping and controls. |
| `TD-200_Technical_Design_Template.docx` | Integrated technical design: business purpose and logic, Top Coat contract, Report (R), Insight (I), Validation (V), Extension (E), screenshots, UAT and release evidence. |
| `DM_Data_Model_Template.xlsx` | Logical and physical APAC consumption model: entities, objects, grain, keys, relationships and changes. |
| `DL_Data_Lineage_Template.xlsx` | Gold View-to-RC/SC/TC lineage, transformation rules, data-flow controls and downstream products. |
| `DD_Data_Dictionary_Template.xlsx` | Field and metric definitions, reference and rollup rules, plus WHO / WHEN audit attributes. |
| `DRIVE_Delivery_Register_Template.csv` | Portfolio, SharePoint List or Excel register of DRIVE enhancement IDs, owners and status. |

Start by assigning the `DRIVE-###` enhancement ID. Complete DA-100 for data architecture work. Complete TD-200 for the consumer delivery; its Report, Insight, Validation and Extension sections are filled in only when relevant. Update the Data Model, Data Lineage and Data Dictionary workbooks when the data foundation changes.

`DA` is the Data Analytics document family. DA-100 contains the Data Architecture (D) design. TD-200 is the Technical Design document that brings together the remaining applicable DRIVE components: Report (R), Insight (I), Validation (V) and Extension (E).

The earlier DRIVE, IV, RP and EX Word templates remain in the repository as reference history only; they are no longer active staff templates.
