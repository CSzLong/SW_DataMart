# DRIVE Template Library

Use this folder as the single staff-download location.

| Template | Use it for |
|---|---|
| `DRIVE_Integrated_Technical_Design_Template.docx` | Every new or changed development requirement. It integrates business logic, DA, VI, RP, EX, validation, operations and release requirements. |
| `DRIVE_Delivery_Register_Template.csv` | Portfolio, SharePoint List or Excel register of DRIVE items and their owners/status. |

Do not create separate DA, VI, RP or EX documents unless a project requires additional depth. Record their linked IDs and use the relevant sections in the integrated design template.
