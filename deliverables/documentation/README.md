# SW Data Mart — Active Documentation

## Active document model

Each enhancement receives a `DRIVE-###` identifier. DRIVE is an enhancement control ID, not a Word document type.

- `DA-100` — Data Architecture Design: Global EDI Gold View dependency, RC/SC processing, data objects, mapping, controls and data foundations.
- `TD-200` — Technical Design: business purpose and logic, Top Coat contract, Report (R), Insight (I), Validation (V), Extension (E), UAT and release evidence.

The active staff templates are in `../template-library/`. A completed DA-100 and/or TD-200 instance should be filed here for each relevant enhancement and linked from the DRIVE register.

## Data foundation workbooks

Maintain the Data Model, Data Lineage and Data Dictionary whenever the RC, SC, TC, semantic model or consumer contract changes.

## Reference history

Earlier component-specific DRIVE, IV, RP and EX templates are retained in the repository as reference history only. New work must use the DA-100 / TD-200 document model.
