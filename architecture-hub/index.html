WHO and WHEN make every data object governable.

These fields belong in the Data Dictionary and the physical design. They make history, ownership, freshness, quality and RLS auditable.

Identity

  • Surrogate key
  • Natural/business key
  • Source system
  • Record hash

WHO

  • Created by
  • Updated by
  • Owner organization
  • Data steward

WHEN

  • Effective from / to
  • Source extract time
  • Load time
  • As-of date

Control + Security

  • Current / deleted flag
  • DQ status / exception
  • Batch ID
  • Legal entity / region
Object-specific additions: REF = entity attributes and hierarchy; MET = all dimension keys, event/snapshot date and measures; LNK = left/right keys and allocation; RUP = aggregation keys, period and aggregation-rule version.

Change flow: request → impact assessment → design approval → build → reconcile → UAT → release → quarterly review.
